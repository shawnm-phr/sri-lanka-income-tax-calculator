# Sri Lanka Income Tax Calculator 2027 (standalone)

Standalone copy of the PeoplesHR page at https://peopleshr.com/sri-lanka-income-tax-calculator/.
Open `index.html` in a browser, or upload the whole folder to any static host. No server, build step or internet connection is needed.

- `index.html`: the page
- `css/sri-lanka-income-tax-calculator.css`: styles, including the site font and colour tokens
- `js/sri-lanka-income-tax-calculator.js`: calculator, rule toggle and tax table
- `fonts/`, `images/`: Plus Jakarta Sans and the flag

Rates: IRD APIT Table 01 for 2025/26 (still applying for 2026/27) and the Budget 2027 proposal (from 1 April 2027, not yet law).
The source of truth is the website repo (PHR Website Dev). Copy changes from there rather than editing this folder.
